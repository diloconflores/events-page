# Content Strategy

## Objetivo

Este proyecto debe desarrollarse bajo una estrategia de **Content First**.

El objetivo es crear contenido que:

- Responda intenciones reales de búsqueda.
- Ayude al posicionamiento orgánico.
- Genere confianza en los usuarios.
- Apoye objetivos comerciales.
- Facilite conversiones.

El contenido no debe crearse únicamente para llenar páginas.

Cada pieza de contenido debe tener un propósito definido.

---

# Principios de Contenido

Reglas principales:

1. Todo contenido debe responder una necesidad del usuario.
2. Cada página debe tener una intención clara.
3. El contenido debe estar orientado a personas, no únicamente a buscadores.
4. Evitar contenido duplicado.
5. Priorizar calidad sobre cantidad.
6. Mantener información actualizada.
7. El contenido debe apoyar una acción o decisión.

---

# Estrategia SEO de Contenido

Antes de crear una nueva página se debe definir:

- Objetivo de la página.
- Intención de búsqueda.
- Keyword principal.
- Keywords secundarias.
- Usuario objetivo.
- Etapa del funnel.
- Acción esperada.

Ejemplo:

```text
Página:

Decoración floral para bodas Monterrey


Objetivo:

Capturar clientes interesados en contratar decoración.


Keyword principal:

decoración floral para bodas Monterrey


Conversión:

Solicitud de cotización.
```

---

# Tipos de Contenido

El proyecto debe diferenciar entre distintos tipos de páginas.

---

# Landing Pages Comerciales

## Objetivo

Convertir usuarios interesados en clientes.

Ejemplos:

- Decoración floral para bodas.
- Eventos corporativos.
- XV años.
- Eventos sociales.

Características:

- Enfoque comercial.
- Beneficios claros.
- Prueba social.
- CTA visible.
- Información de contacto.

---

# Páginas Informativas

## Objetivo

Responder preguntas y captar tráfico orgánico.

Ejemplos:

- Tipos de arreglos florales para bodas.
- Cómo elegir flores para un evento.
- Tendencias de decoración floral.

Características:

- Mayor profundidad.
- Educación del usuario.
- Enlaces hacia páginas comerciales.

---

# Intención de Búsqueda

Cada página debe responder una intención específica.

Tipos:

---

## Informacional

Usuario busca aprender.

Ejemplo:

```text
qué flores usar para una boda
```

---

## Comercial

Usuario compara opciones.

Ejemplo:

```text
decoración floral bodas Monterrey
```

---

## Transaccional

Usuario quiere contratar.

Ejemplo:

```text
cotizar decoración floral boda
```

---

# Keyword Strategy

Las keywords deben utilizarse naturalmente.

Priorizar:

- Título.
- H1.
- Primeros párrafos.
- Encabezados.
- Metadata.
- Texto alternativo cuando aplique.

Evitar:

- Keyword stuffing.
- Repetición artificial.
- Textos creados únicamente para buscadores.

---

# Contenido Comercial

Las páginas comerciales deben transmitir:

- Confianza.
- Experiencia.
- Diferenciadores.
- Proceso.
- Calidad.
- Resultados.

No deben enfocarse únicamente en precios.

---

# Propuesta de Valor

Cada página debe responder:

## ¿Qué ofrecemos?

Ejemplo:

```text
Diseñamos decoración floral personalizada para bodas y eventos.
```

---

## ¿Por qué elegirnos?

Ejemplo:

```text
Más de X años creando experiencias florales.
```

---

## ¿Qué obtiene el cliente?

Ejemplo:

```text
Un evento visualmente memorable sin preocuparse por la coordinación floral.
```

---

# Contenido Multilenguaje

Todo contenido debe considerar internacionalización.

Reglas:

- Español será el idioma base.
- Inglés será traducción del contenido original.
- No traducir literalmente cuando afecte intención.
- Adaptar keywords por idioma.
- Mantener URLs traducidas.

Ejemplo:

Español:

```text
/bodas
```

Inglés:

```text
/weddings
```

---

# Traducción SEO

Cada idioma debe tener:

- Title localizado.
- Meta description localizada.
- H1 localizado.
- Keywords adaptadas.
- Slugs traducidos.

No utilizar traducción automática sin revisión.

---

# Contenido Dinámico

Cuando exista contenido generado desde datos:

Debe mantener:

- HTML indexable.
- Metadata correcta.
- Estructura semántica.

Evitar:

- Contenido crítico generado únicamente con JavaScript.

---

# Imágenes y Contenido Visual

Las imágenes forman parte del contenido.

Cada imagen debe:

- Apoyar el mensaje.
- Tener nombre descriptivo.
- Tener alt relevante.
- Estar optimizada.

Ejemplo:

Incorrecto:

```text
DSC00452.webp
```

Correcto:

```text
decoracion-boda-jardin-monterrey.webp
```

---

# Prueba Social

Cuando aplique incluir:

- Testimonios.
- Casos reales.
- Fotografías de eventos.
- Opiniones.
- Reconocimientos.

Debe utilizarse contenido real.

---

# FAQ Strategy

Las preguntas frecuentes deben responder dudas reales.

Ejemplos:

- ¿Con cuánto tiempo debo reservar?
- ¿Qué incluye la decoración?
- ¿Trabajan eventos grandes?
- ¿Qué zonas cubren?

Evitar crear FAQs únicamente para agregar keywords.

---

# Actualización de Contenido

El contenido debe mantenerse vigente.

Revisar periódicamente:

- Información comercial.
- Servicios.
- Fotografías.
- Tendencias.
- Datos de contacto.

---

# Contenido y Conversión

Toda página comercial debe tener una acción clara.

Ejemplos:

- Solicitar cotización.
- Contactar por WhatsApp.
- Agendar asesoría.
- Ver portafolio.

Evitar páginas sin objetivo.

---

# Validación de Nuevo Contenido

Antes de publicar una nueva página verificar:

```text
Nueva página

↓

Definir intención SEO

↓

Investigar keywords

↓

Crear contenido original

↓

Agregar metadata

↓

Agregar enlaces internos

↓

Validar idioma

↓

Validar SEO

↓

Publicar
```

---

# Regla Final

El contenido es el puente entre el usuario y el producto.

Una arquitectura técnicamente perfecta no tendrá impacto si el contenido no responde necesidades reales.

Cada página debe existir porque aporta valor, resuelve una intención y acerca al usuario a una acción.
